# Módulo Restore

Este módulo fornece interfaces para restauração automática do backup do banco de dados e dos arquivos de um sistema Dolibarr.

Funcionalidades:
- Restauração de banco de dados a partir de arquivos SQL
- Restauração de arquivos (documentos) a partir de arquivos comprimidos

Instalação:
1. Copie a pasta `restore` para o diretório `htdocs/custom/`.
2. Acesse Dolibarr como administrador, vá em `Configuração > Módulos` e ative o módulo **Restore**.
3. Utilize os menus em `Home > Ferramentas` para acessar as páginas de restauração.
